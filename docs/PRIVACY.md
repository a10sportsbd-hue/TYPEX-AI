# TYPEX AI Privacy Baseline

1. Do not log typed text or surrounding text from InputConnection.
2. Do not transmit text unless the user explicitly invokes an AI action.
3. Disable learning and AI features in password and sensitive input fields.
4. Keep dictionaries and personalization local by default.
5. Request microphone permission only when the user starts voice typing.
6. Do not request Accessibility Service permission for normal keyboard operation.
7. Provide clear controls to clear local history and disable personalization.
8. Never embed provider API secrets in the APK.
